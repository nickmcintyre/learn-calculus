# Audio Data

The *c_major_flute.npy* and *c_major_moog.npy* files were generated using the ChucK programming language (https://chuck.stanford.edu/). The *c_major_sawtooth.npy* and *c_major_square.npy* files were generated using the SciPy package (https://scipy.org/).
